## La Marque

La marque cest le nom lentité la structure qui représente une personne ou une org

Elle permet:
- D'etre id (qui somme-nous ?)
- D'etre reconnue (a qui elle appartient ?)
- Fédérer (que représente la marque)

Flyers, doc pro, communiqué de presse

## L'identité

L'id cest ce que la marque transmet volontairement
Cest l'adn dela marque : valeur, style; ton, univers

Elle répond à:
- Qui suisje et questce que je fais

Limage des marque traduit un état d'esprits et crée une attente

## Le branding

**Le branding est la façon dont on construit et exprime l'id**

Cest l'ensemble des éléments visible et perceptibles
- Logo, couleur, typographie
- Ton (sérieux, humour)
- support (flyers, réseaux sociaux)
- Ambiance visuelle, manière de raconter

==Le branding est une stratégie==
==Elle oriente la perception==

## Le persona

Un persona est un profil type d'interlocuteur que l'on crée pour mieux comprendre à qui in veut comm

Cest une personne fictive mais réaliste, qui représent un type de public

Il peut etre: Client

**Un personna nest pas:**
- un jugement
- une caricature
- une case dans laquelle enfermer les gens
4 clée pour créer


| Question            |                         |
| ------------------- | ----------------------- |
| Aui                 | age, situation, énergie |
| Que cherche til     | comprendre              |
| Q'uatten til de moi | clarté                  |
| ton                 | chaleureux              |

Modèle
- Nom
- Age
- Energie (détendue / rapide)
- Motivation de visite (curio, apprentissage)
- Besoin émotion
- Niveau attention
- Style de comm

### Avantages
- prod contenu pertinent
- Perso les intéraction 
- Faire la diff avec les autres
- Analyse le comportement

## Méthode AIDA


| Lettre | Signification | Objectif                            |
| ------ | ------------- | ----------------------------------- |
| A      | Attirer       | Accrocher des le debut              |
| I      | Intéresser    | Montrer que le sujet le concerne    |
| D      | Désirer       | Donner envie / créer une projection |
| A      | Agir          | Inviter a passer a l'action         |
Orde naturel dans lequel le cerveau traite

Si on attire pas - personne ecoute
Si intéresse pas - ca concerne pas
Si on donne pas envie - ca reste une info
si on propose pas d'action - rien ne passe

A Et si je vous disais quon peut captiver une personne des les 3 premiers mots
I Parce que vous futur métier repose sur la manière dont vous allez vous faire écoute
D Vous pouvez gagner un impact des vos premiere minutes
A On tente un phrase d'accroche maintenant
